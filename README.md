# SQL Lab: תרגול SQL

אתר מקומי לתרגול SQL ברמה בסיסית, בינונית ומתקדמת, עם שאלות בסגנון מבחני בית בחברות.

## איך מפעילים
פותחים את `index.html` בלחיצה כפולה. צריך חיבור לאינטרנט כדי לטעון את הספריות מ-CDN.

## איך זה עובד
1. בוחרים רמה. רשימת השאלות מופיעה בצד שמאל.
2. כותבים שאילתה ולוחצים על "הרץ" (או על Ctrl+Enter).
3. אם הפלט זהה לפלט הצפוי, השאלה מסומנת "בוצע". שמות העמודות לא נבדקים, ובדרך כלל גם לא סדר השורות, אלא אם השאלה מבקשת מיון.
4. ההתקדמות נשמרת בדפדפן (localStorage).

## קבצים
1. הקובץ `data.js` מכיל את הסכמה ואת נתוני הדוגמה.
2. הקבצים `questions.js` ו-`questions_extra.js` מכילים את השאלות (המקוריות, ואלה שמבוססות על DataLemur, LeetCode ו-StrataScratch). הנתונים שלהן נמצאים ב-`data.js` וב-`data_extra.js`. כדי להוסיף שאלה, מוסיפים אובייקט עם `id`, `level`, `topic`, `title`, `tables`, `prompt`, `solution` ו-`ordered`.
3. הקובץ `app.js` מכיל את הלוגיקה. בקונסול אפשר להריץ `selfTest()` כדי לבדוק שכל הפתרונות רצים.

## גרסה מפורסמת
הפקודה `python build_artifact.py` בונה את `dist/sql-lab.html`, וזה הקובץ שמתפרסם כעמוד ב-claude.ai.

## שאלות יומיות
משימה מתוזמנת מוסיפה כל יום 5 שאלות לכל רמה לקבצים `questions_daily.js` ו-`data_daily.js`, בודקת אותן עם `node verify.js`, ומפרסמת מחדש.
